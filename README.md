# Student Dashboard

This project was created with the aim of learning concepts in react by actually working on a project rather than simply going theory lessons.

---

### How to get started: 

```bash

npm install 
# installs required modules

npm audit
# to see all audit logs and warnings for versioning errors and stuff

npm run lint 
# to run a linting check

npm run dev
# to see the dev run in localhost

```
